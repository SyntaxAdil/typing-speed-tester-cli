# ⌨️ Python Typing Speed Test

A simple terminal-based typing speed tester built with Python.

### Features

- Random sentence selection
- Typing speed calculation (WPM)
- Accuracy measurement
- Time tracking
- Character count

### Run Locally

**1. Clone the repository**

```bash
git clone https://github.com/SyntaxAdil/typing-speed-tester-cli
cd typing-speed-tester
```

**2. Run the program**

```bash
python3 main.py
```

### Built With

- Python 3
- `random`
- `time`

No external dependencies required.
